# 植物観察日記アプリ 要件定義書

**バージョン**: 1.1  
**作成日**: 2026-05-18  
**対象プラットフォーム**: iOS / Android（React Native + Expo）

---

## 1. プロダクト概要

### 1.1 目的

小学生から大人まで、植物の成長を継続的に記録・観察できるスマートフォンアプリを提供する。朝顔の夏休み観察日記から観葉植物の日常管理まで幅広い用途に対応する。

### 1.2 対象ユーザー

| セグメント | 主なユースケース |
|---|---|
| 小学生 | 朝顔・ひまわりなど学校の観察日記（夏休み宿題） |
| 保護者 | 子どもと一緒に記録、学習サポート |
| 一般成人 | 観葉植物・家庭菜園の継続管理 |

### 1.3 スコープ

- **フレームワーク**: React Native + Expo
- **認証**: ローカルデータのみ（単一デバイス、アカウント不要）
- **言語**: 日本語（初回リリース）
- **配信方針**: 無料（広告なし）

---

## 2. 機能要件

### 2.1 植物管理

#### 2.1.1 植物の登録・管理

- 複数の植物をそれぞれ独立して管理できる
- 植物ごとに以下の基本情報を設定できる
  - 名前（例：「朝顔1号」「モンステラ」）
  - 種類・品種（テキスト入力 or プリセット選択）
  - 栽培開始日
  - サムネイル写真（プロフィール画像として設定）
  - メモ（置き場所、品種特性など）
- 植物の削除・アーカイブができる

#### 2.1.2 ホーム画面

- 登録済み植物の一覧を表示する
- 各植物カードに「最終記録日」「今日記録済みかどうか」「ストリーク日数」を表示する
- 未記録の植物を視覚的に区別できる（バッジ等）

---

### 2.2 観察記録

#### 2.2.1 日次記録の登録

1日1レコードを基本とし、以下の項目を記録できる。

| 項目 | 入力方式 | 必須 |
|---|---|---|
| 記録日 | 日付ピッカー（デフォルト：今日） | ○ |
| 写真 | カメラ撮影 or ライブラリ選択（最大3枚/日） | - |
| テキストメモ | 自由記述（最大500文字） | - |
| 天気 | アイコン選択（晴/曇/雨/雪/その他）+ 自由テキスト入力 | - |
| 気温 | 数値テキスト入力（℃） | - |
| 観察テンプレート項目 | 項目別入力（後述） | - |

#### 2.2.2 観察テンプレート

植物種別ごとにデフォルトテンプレートを提供する。ユーザーがカスタマイズ可能とする。

**朝顔テンプレート（例）**

| 項目名 | 入力型 | 単位 |
|---|---|---|
| 草丈 | 数値 | cm |
| 葉の数 | 整数 | 枚 |
| つぼみの数 | 整数 | 個 |
| 開いた花の数 | 整数 | 個 |
| 花の色 | カラーパレット選択 or テキスト | - |
| 全体の様子 | 3段階評価（元気/普通/元気なし） | - |

**観葉植物テンプレート（例）**

| 項目名 | 入力型 | 単位 |
|---|---|---|
| 草丈・高さ | 数値 | cm |
| 葉の状態 | 選択（青々/黄化/斑点あり） | - |
| 水やり実施 | トグル | - |
| 土の乾き具合 | 3段階（乾燥/適度/湿潤） | - |

#### 2.2.3 記録の編集・削除

- 過去の記録を編集・削除できる
- 写真の追加・削除も可能とする（上限3枚を超えない範囲）

---

### 2.3 閲覧・可視化

#### 2.3.1 カレンダービュー

- 月次カレンダーで記録の有無を確認できる
- 記録がある日付にはサムネイル写真またはアイコンを表示する
- 日付タップで該当日の記録詳細に遷移できる

#### 2.3.2 成長グラフ

- テンプレート内の数値項目（草丈など）を折れ線グラフで表示する
- 横軸：記録日、縦軸：計測値
- 複数項目を切り替えて表示できる
- 期間フィルター（直近1ヶ月/3ヶ月/全期間）を備える

#### 2.3.3 成長タイムライン

- 写真を時系列順でスライドショー/パラパラ表示できる
- 写真がない日はスキップする
- 各写真に記録日付を表示する

---

### 2.4 通知・リマインダー

- ユーザーが通知時刻を設定できる（デフォルト：毎日18:00）
- 当日に記録がない場合のみ通知を送信する（記録済みの場合は送信しない）
- 通知メッセージ例：「今日の〇〇（植物名）の観察を記録しよう！」
- 植物ごとにON/OFFを設定できる

---

### 2.5 ゲーミフィケーション

#### 2.5.1 ストリーク

- 連続記録日数を植物ごとにカウントする
- 連続記録が途切れた場合はリセットされる
- ホーム画面・記録詳細画面にストリーク日数を表示する

#### 2.5.2 達成バッジ

| バッジ名 | 解除条件 |
|---|---|
| はじめての観察 | 初めて記録を作成する |
| 3日連続 | 3日連続で記録する |
| 1週間連続 | 7日連続で記録する |
| 1ヶ月連続 | 30日連続で記録する |
| 写真コレクター | 合計30枚の写真を記録する |
| 観察マスター | 合計100件の記録を作成する |
| 成長の記録者 | 成長グラフを初めて閲覧する |

- バッジ獲得時にアニメーション演出を表示する
- バッジ一覧画面で獲得済み・未獲得を確認できる

#### 2.5.3 スタンプ・絵文字

- 1日の記録に気分スタンプを1つ添付できる
- スタンプ候補：☀️🌱🌸🌿💧🐛😊 等（子ども向けビジュアル）
- カレンダービューにスタンプを表示する

---

## 3. デザイン方針

### 3.1 基本方針

- 小学生から大人まで迷わず操作できるシンプルなUIとする
- 子ども向けのキャラクター・装飾的要素は使用しない
- アイコンと短いラベルを組み合わせ、文字が読めない年齢層も操作できるよう配慮する
- 操作の深さは最大3タップ以内を目標とする

### 3.2 テーマ機能

- ライト / ダーク の2テーマを提供し、設定画面から切り替えられる
- 将来的な追加テーマ（グリーン系・ナチュラル系など）に備え、テーマをトークン（色変数）で管理する
- 端末のシステム設定（ダークモード自動）に追従するオプションも設ける

### 3.3 技術実装指針（React Native + Expo）

| 用途 | ライブラリ候補 |
|---|---|
| ナビゲーション | Expo Router（ファイルベース） |
| カメラ・画像選択 | expo-camera / expo-image-picker |
| ローカルDB | expo-sqlite |
| 画像ファイル保存 | expo-file-system |
| プッシュ通知 | expo-notifications |
| カレンダーUI | react-native-calendars |
| グラフ（将来） | react-native-gifted-charts / victory-native |
| テーマ管理 | React Context + StyleSheet トークン |

## 4. 非機能要件

### 4.1 パフォーマンス

- 画像は保存時にリサイズ・圧縮する（最大1280px長辺、JPEG品質80%）
- 記録一覧・カレンダーのスクロールはスムーズに動作する（60fps目標）

### 4.2 データ保存

- 全データはローカルデバイスに保存する
- DB: expo-sqlite（SQLite）
- 画像ファイルは expo-file-system 経由でアプリの Documents ディレクトリに保存する

### 4.3 アクセシビリティ

- 操作ボタンのタップ領域は最小44×44pt を確保する
- テキストサイズは端末の文字サイズ設定に追従する

### 4.4 セキュリティ

- アプリ内データは端末ストレージ内にとどめる
- 外部通信は行わない（通知はローカル通知を使用）

## 7. データモデル（概要）

成長グラフ（S06）は MVP 対象外だが、**記録入力時からグラフ用データを蓄積**するため、テンプレート項目・観察値テーブルは MVP から実装する。

```
Plant（植物）
  - id            INTEGER PRIMARY KEY
  - name          TEXT NOT NULL          -- 植物名（例：朝顔1号）
  - species       TEXT                   -- 種類・品種
  - start_date    TEXT                   -- 栽培開始日（ISO8601）
  - thumbnail_path TEXT                  -- サムネイル画像パス
  - memo          TEXT                   -- 備考
  - created_at    TEXT

DiaryEntry（日次記録）
  - id            INTEGER PRIMARY KEY
  - plant_id      INTEGER NOT NULL       -- FK: Plant.id
  - recorded_at   TEXT NOT NULL          -- 記録日（ISO8601 date）
  - weather       TEXT                   -- 天気選択値（sunny/cloudy/rainy/snowy/other）
  - weather_note  TEXT                   -- 天気自由入力（補足）
  - temperature   REAL                   -- 気温（℃）
  - memo          TEXT                   -- テキストメモ（最大500文字）
  - stamp         TEXT                   -- 気分スタンプ（絵文字コード）
  - created_at    TEXT

Photo（写真）
  - id            INTEGER PRIMARY KEY
  - entry_id      INTEGER NOT NULL       -- FK: DiaryEntry.id
  - file_path     TEXT NOT NULL          -- ローカルファイルパス
  - sort_order    INTEGER                -- 表示順（0-2）
  - created_at    TEXT

TemplateItem（テンプレート項目定義）
  - id            INTEGER PRIMARY KEY
  - plant_id      INTEGER NOT NULL       -- FK: Plant.id（植物ごとにカスタマイズ可）
  - label         TEXT NOT NULL          -- 項目名（例：草丈、葉の数）
  - input_type    TEXT NOT NULL          -- number / integer / select / toggle / color
  - unit          TEXT                   -- 単位（cm、枚 など）
  - options       TEXT                   -- selectの選択肢（JSON配列）
  - sort_order    INTEGER
  - is_graphable  INTEGER DEFAULT 1      -- 成長グラフに使用するか（1=yes）

ObservationValue（観察項目値）※グラフデータの蓄積元
  - id            INTEGER PRIMARY KEY
  - entry_id      INTEGER NOT NULL       -- FK: DiaryEntry.id
  - template_item_id INTEGER NOT NULL    -- FK: TemplateItem.id
  - value_text    TEXT                   -- 文字列として汎用保存
  - value_number  REAL                   -- 数値項目は別途保持（グラフ用）

Badge（バッジ）
  - id            INTEGER PRIMARY KEY
  - badge_type    TEXT NOT NULL          -- バッジ種別コード
  - unlocked_at   TEXT                   -- 解除日時（NULLは未獲得）
```

|---|---|---|---|

| 開いた花の数 | integer | 個 | 1 |

## 9. 確定済み設計メモ

### テーマカラー

植物日記らしい生命力・ほのぼの感を基調とする。ダークテーマは不要。

| トークン名 | 用途 | カラー例 |
|---|---|---|
| `color.primary` | メインアクション、強調 | 緑系（例：#4CAF50） |
| `color.secondary` | サブアクション、アクセント | 黄緑系（例：#8BC34A） |
| `color.accent` | バッジ、ストリーク強調 | オレンジ / 黄色系（例：#FFA726） |
| `color.background` | 画面背景 | オフホワイト（例：#FAFAF6） |
| `color.surface` | カード背景 | 白（例：#FFFFFF） |
| `color.text.primary` | 本文テキスト | ダークグレー（例：#2E2E2E） |
| `color.text.secondary` | サブテキスト | ミドルグレー（例：#757575） |

将来のテーマ追加に備え、全カラーを Context の theme トークンで管理し、StyleSheet にハードコードしない。

### ストリーク仕様

- 連続記録日数を植物ごとにカウントする
- **2日間の猶予あり**：最後の記録日から2日以内に再記録すれば連続扱いとする
- 3日以上記録がない場合はストリークをリセットする
- ホーム画面の植物カードにストリーク日数を表示する（例：🔥 5日連続）

### 植物種別プリセット

登録時に種別を選ぶとテンプレート項目が自動セットされる。

| 種別 | 主な対象ユーザー |
|---|---|
| 朝顔 | 小学生の夏休み観察日記 |
| 観葉植物 | 室内植物を管理する大人 |
| 野菜・家庭菜園 | 家庭菜園・ベランダ栽培 |
| カスタム | 上記以外（テンプレート項目を自由設定） |
